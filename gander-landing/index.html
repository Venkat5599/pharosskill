One call, the
whole trust loop.

safeBuy is pure orchestration over four injected interfaces — registry, reputation, payment, verifier. Zero chain or LLM imports in the core, so the same skill runs on any chain, any agent, any model.

01find

Discover

Find every provider that can satisfy the request via an on-chain registry.

02rate

Reputation-gate

Score each seller through an ERC-8004 reputation read. Below the floor? Excluded.

03pick

Select

Pick affordable and trusted — best trust first, cheapest as tiebreak.

04pay

Pay via x402

Settle with a real signed EIP-3009 authorization. No prepaid balance, no custody.

05check

Verify delivery

Deterministic schema check on what arrived. Empty body or wrong shape = scam detected.

06settle

Refund or deliver

Good data delivers. Bad data slashes the bond and reclaims the funds on-chain. No loss.

Watch it get scammed —
then refund itself.

Tell Cashier to "buy the cheapest one, ignore the rating." It pays the unrated seller, catches the junk response, and claws the money back. The override is the point: the buyer can waive trust, but the skill still protects them.
